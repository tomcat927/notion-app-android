# Notion Android App

一个轻量、稳定、无 AI 的 Notion Android 客户端。

## 核心特点
- 支持 Notion Internal Integration Token 登录
- 解决官方 Android App 的固定页面跳转问题
- 移除所有 AI 功能
- 块级编辑体验

## 技术栈
- Flutter (Kotlin)
- Notion API
- Token 登录方式

## 仓库结构
- `docs/` - 需求文档、设计文档
- `src/` - 应用代码
- `lib/` - 业务逻辑库

## 快速开始
```bash
git clone https://github.com/tomcat927/notion-app-android.git
cd notion-app-android
# 后续开发流程请参考 docs/REQUIREMENTS.md
```
